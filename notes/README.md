# XKE.DotNet8 / notes

本目录是 `XKE.DotNet8` 的工程记录与事实索引入口。

## 子目录说明
- `core-index/`：当前 Python 项目的核心事实索引
- `sensitive-index/`：敏感边界、禁止复制规则与受控路径清单
- `module-boundaries/`：未来 .NET 模块边界草图
- `api-parity/`：围绕 Python -> .NET 契约、数据、控制平面对齐的持续记录

## 根级文件说明
- `00_migration_roadmap.md`：当前迁移路线总览
- `12_模块维度详细变更清单.md`：已完成工作的模块化台账

## 维护规则
- notes 只记录已经落地的事实、验收结论和兼容结论，不替代代码推进
- 每当完成一段具有可累积价值的重构工作，再补对应的 parity 或模块记录
- 记录以“已完成事实”为主，不把纯设想写成已完成
- 任何涉及真实密钥、真实 data、真实录包的信息，都不能直接写入这里

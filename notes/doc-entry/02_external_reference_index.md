# 外部文档引用索引

本文件只记录 `XKE.DotNet8` 重构开发可参考的外部文档位置和使用规则。外部文档不自动成为当前开发决策源。

## 引用原则

- 产品说明只用于理解用户视角，不进入后端实现决策。
- 旧重构计划只做事实参考和结论提炼，不复制原文到 `notes`。
- 受限资料只允许路径级索引，不复制真实账号、密码、token、Cookie、`.env`、录包或原始响应。
- 若外部文档与当前 `roadmap`、`review-issues` 或 `sensitive-index` 冲突，以 `XKE.DotNet8/notes` 当前文档为准。

## 外部入口

| 路径 | 类型 | 用途 | 处理规则 |
| --- | --- | --- | --- |
| `Z:/XKE/docs/项目说明/` | 产品/用户说明 | 理解功能、用户可见文案和旧产品定位 | 只引用，不迁入 |
| `Z:/XKE/重构计划/` | 旧重构规划与事实冻结 | 提炼仍适用于 .NET 重构的架构、契约、迁移和风险结论 | 只提炼，不整体迁入 |
| `Z:/XKE/重构计划/90_受限资料/` | 受限资料 | 仅用于确认真实链路资料所在位置 | 只做路径级索引，不复制正文 |
| `Z:/XKE/reference-archive/` | 历史归档 | 保存已停止活动的一次性材料和旧文档 | 只作离线参考 |

## 可提炼目标

- 架构与模块边界：提炼到 `module-boundaries/` 或 `core-index/`。
- API 与兼容契约：提炼到 `api-parity/`。
- 迁移阶段与验收：提炼到 `roadmap/`。
- 问题、风险和暂缓项：提炼到 `review-issues/`。
- 敏感路径和外部资料规则：提炼到 `sensitive-index/`。

## 禁止做法

- 不把 `docs/项目说明` 当作后端 API 或存储模型依据。
- 不把 `重构计划` 中的旧 Python 实现描述直接复制为 `.NET` 当前事实。
- 不把 `90_受限资料` 中任何真实值写入 `notes`、fixtures、测试或工具默认值。

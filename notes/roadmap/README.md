# roadmap

本目录保存当前重构方向、阶段总结和迁移计划提炼。

## 文件

- [00_development_direction.md](./00_development_direction.md)：当前主线、术语和下一阶段优先级。
- [01_phase_summary.md](./01_phase_summary.md)：阶段总结、已完成切片和当前门禁。
- [02_migration_plan_extract.md](./02_migration_plan_extract.md)：旧迁移计划中仍适用的阶段顺序和验收口径。

## 规则

- 只记录阶段方向和验收口径。
- 具体开发步骤放入 `development-docs/`。
- 长期资料和敏感边界放入 `sensitive-index/`。

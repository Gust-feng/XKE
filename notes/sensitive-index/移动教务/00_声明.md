# 移动教务资料声明

本目录只整理“移动教务”相关资料。这里的移动教务指当前 `XKE.DotNet8` 已接入的移动端登录、移动 token、移动课表和本地课表恢复链路，不包括传统 Web 教务系统。

## 当前定位

移动教务是当前主链路，传统教务系统开发期间应保持移动教务行为不变。

移动教务负责：

- 用户首次登录初始化
- 移动端 `getKey -> AES 密文 -> login -> token` 认证
- 1 小时内复用本地受保护的移动教务加密密文
- 运行期 token 刷新，不把 token 作为本地工作区恢复前置条件
- `/api/auth/login`
- `/api/auth/connect`
- `/api/auth/session`
- `/api/schedule/preferred`
- `/api/schedule/local`
- 移动课表 fixture 与 smoke 工具索引

## 不属于本目录的内容

- 传统 Web 教务系统登录
- 验证码 / OCR / Cookie 登录链路
- 传统教务课表 HTML
- 传统教务 Cookie header
- 传统教务课程查询、选课轮次、课程预览、抢课链路

上述内容统一放入 `notes/sensitive-index/教务系统/`。

## 传统教务开发期间的保护边界

- 不为了实现 `/api/schedule/cookie` 改变 `/api/schedule/preferred` 的移动教务行为
- 不把传统教务 Cookie 写入移动教务 token 存储
- 不把移动 token 当作传统 Web 教务 Cookie 使用
- 不让 `course/*` deferred 改动影响移动课表刷新
- 不把移动教务 fixture 与传统教务 HTML fixture 混放

## 允许写入本目录的内容

- 移动教务相关代码路径、类名、方法名
- API 路径、请求字段名、响应字段名
- 环境变量名和假值占位符
- 移动教务 smoke 命令模板
- 移动链路回归清单
- 已脱敏的 `fixtures/mobile/`、`fixtures/schedule/` 路径和用途说明

## 禁止写入本目录的内容

- 真实账号、真实密码、真实 trusted login token
- 真实移动 token、真实 Cookie、真实 session id
- 真实请求头、真实原始响应或录包正文
- 真实 `data/` 镜像
- 传统 Web 教务验证码图片或课表 HTML 原文

## 阅读顺序

1. 先读本文件，确认移动教务与传统教务边界
2. 再读 `01_认证流程索引.md`，按现有移动链路做回归或补充开发
3. 再读 `02_运行边界与回归清单.md`，确认已完成链路的状态语义和失败边界
4. 传统 Web 教务开发请切到 `notes/sensitive-index/教务系统/`

## 当前实现状态

移动教务链路已作为当前可用主线：

- 首次 `auth/login` 可完成本地初始化和移动课表拉取
- 本地登录和 session 恢复不会自动连接远端
- `auth/connect` 用于重新建立移动端连接
- `schedule/preferred` 用于刷新移动课表
- `schedule/local` 用于读取本地课表缓存
- `MobileJwLoginClient` 已统一 Auth 与 Schedule 的移动端登录逻辑
- 本地凭据中的 `MobileJw` 保存移动教务加密密文及 TTL，不保存可作为长期会话的移动 token

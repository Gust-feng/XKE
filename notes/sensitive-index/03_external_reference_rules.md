# 外部资料引用规则

> 2026-10-07 路径说明：本文件中的旧 Python `Z:/XKE/...` 路径仅用于历史来源标识。对应目录已归档到当前仓库 ignored 的 `开发数据/历史工程/旧Python工程.zip`，不代表当前活动工程下仍有这些文件，也不参与运行。


本文件规定 `XKE.DotNet8/notes` 如何引用旧 XKE 文档、重构计划和受限资料。

## 总原则

- `notes` 保存当前 .NET 重构开发依据，不保存旧 XKE 文档全集。
- 外部文档只允许通过路径、用途和处理规则引用。
- 真实敏感资料不迁入 `XKE.DotNet8`。
- 需要进入 tests 或 fixtures 的样本必须先脱敏。

## 外部资料分类

| 来源 | 是否迁入 notes | 允许内容 | 禁止内容 |
| --- | --- | --- | --- |
| `Z:/XKE/docs/项目说明/` | 否 | 路径、用途、产品视角说明 | 将用户说明改写成后端契约 |
| `Z:/XKE/重构计划/00-09/` | 只提炼 | 当前仍有效的架构、契约、迁移、风险结论 | 原文整搬、旧 Python 当前事实 |
| `Z:/XKE/重构计划/90_受限资料/` | 否 | 路径级索引、敏感等级、处理规则 | 真实账号、密码、token、Cookie、`.env`、录包、原始响应 |
| `Z:/XKE/reference-archive/` | 否 | 归档入口说明 | 重新作为活动决策源 |

## 引用格式

- 记录路径时只写目录或文件用途，不写真实内容。
- 需要说明请求字段时使用占位符，例如 `<TEST_USER>`、`<SESSION_ID>`、`<REDACTED>`。
- 需要描述真实链路时只写阶段和行为，不写请求头、Cookie header、token、原始响应正文。

## 检查要求

新增或更新 notes 后，应检查：

- 不出现真实账号和真实密码。
- 不出现真实 token、Cookie、JSESSIONID、Authorization header。
- 不出现真实 `.env` 原文、私钥、录包、原始响应正文。
- 不把移动教务和传统教务术语混用。

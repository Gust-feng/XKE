# 教务系统资料声明

本目录只整理“传统 Web 教务系统/JW”相关资料。这里的教务系统不等同于移动教务，移动教务资料统一放在 `notes/sensitive-index/移动教务/`。

本目录是长期资料库，不表示当前开发进度。当前传统教务 Cookie 课表开发状态以 [development-docs/traditional-jw-cookie-schedule](../../development-docs/traditional-jw-cookie-schedule/README.md) 为准。

## 长期目标

v1 目标是恢复传统 Web 教务的“登录 + Cookie 课表”闭环：

- 完成传统 SSO 预登录
- 建立传统 SSO/JW 登录流程
- 维护 Cookie / Session / 请求上下文
- 接入 `/api/schedule/cookie`
- 拉取传统教务课表 HTML
- 解析为 `jw_schedule` 课表数据
- 写入本地课表缓存，并支持 `/api/schedule/local` 读取

## 登录态硬性规则

- 预登录是必经阶段，不是可选优化。
- Cookie 不是登录入口，只是 `login_portal -> bootstrap_jw_session` 成功后的派生产物。
- `/api/schedule/cookie` v1 必须内部完成传统 SSO 预登录、SSO 登录、JW ticket 换取、`/jsxsd` 路径登录态校验后，才能请求课表 HTML。
- 不支持“外部传入 Cookie 直接当登录态”的实现路线。
- Cookie header、Cookie bundle、JW `JSESSIONID` 只能由登录流程生成或刷新，不能作为 API 请求体中的入口凭据。
- `cookie_rq` 只表示传统教务课表查询日期/周次参数，不表示 Cookie。

## 当前不做

- 不把 `course/grab` 作为第一阶段目标
- 不在第一阶段实现真实抢课轮询、提交或自动重试
- 不在本目录保存真实录包、真实响应、真实请求头或真实验证码图片
- 不把移动教务 token、移动课表或移动端登录流程写入本目录

课程查询、轮次、预览、抢课资料可以在本目录做路径索引，但实现顺序排在 Cookie 课表闭环之后。

## 允许写入本目录的内容

- 代码路径、模块名、类名、方法名
- API 路径、请求字段名、响应字段名
- 环境变量名，例如 `user`、`password`、`prelogin_mode`、`cookie_rq`
- 使用占位符的假样例，例如 `<TEST_USER>`、`<TEST_PASSWORD>`、`<SESSION_ID>`
- smoke 命令模板
- 验收步骤、错误码、失败场景和开发任务拆分
- 已脱敏 fixture 的路径、用途和结构说明

## 禁止写入本目录的内容

- 真实账号、真实密码、真实 trusted login token
- 真实 Cookie、真实 token、真实 session id
- 真实 `.env` 原文
- 完整真实请求头
- 真实验证码图片或 OCR 原始输出
- 真实 HTML / XML / JSON 原始响应正文
- 真实 `data/` 镜像或浏览器 profile
- `Z:/XKE/重构计划/90_受限资料/` 中的任何原文

## 资料处理规则

- 只记录路径、用途、流程阶段和敏感等级
- 真实资料只允许原地只读引用，不复制进 `XKE.DotNet8/`
- 需要测试样本时，先制作结构保真的脱敏 fixture
- 开发态测试账号可以使用，但只能通过本地环境变量、测试机配置或原开发资料位置读取
- 文档中的命令只能写占位符或环境变量名，不能写真实值

## 阅读顺序

1. 先读本文件，确认传统教务系统边界
2. 再读 `01_接入资料索引.md`，按 v1 登录 + Cookie 课表流程开发
3. 需要确认移动教务行为时，切到 `notes/sensitive-index/移动教务/`

## 当前实现状态

`XKE.DotNet8` 当前对传统 Web 教务仍是后置接入状态：

- `/api/schedule/cookie` 当前返回未接入提示
- `/api/course/connect`、`/api/course/rounds`、`/api/course/preview` 当前以 deferred 语义为主
- `/api/course/grab/start`、`/api/course/grab/stop` 当前返回 `501`

后续开发应优先让 `/api/schedule/cookie` 从 deferred 变为真实“预登录 + 传统 SSO/JW 登录 + Cookie 课表刷新”入口，移动教务接口保持原行为不变。

当前实际开发过程和任务板不在本目录维护；请查看 [traditional-jw-cookie-schedule/02_task_board.md](../../development-docs/traditional-jw-cookie-schedule/02_task_board.md)。

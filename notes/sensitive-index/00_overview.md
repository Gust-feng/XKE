# 敏感边界总览

本目录只保存敏感边界的**元数据索引**，不保存真实内容。

## 目标
- 标记哪些路径属于高敏区域
- 明确哪些内容禁止复制到 `XKE.DotNet8/`
- 为后续脱敏样本、兼容验证、发布排查提供依据

## 索引文件
- `01_boundary_rules.md`：统一规则
- `02_sensitive_paths.md`：关键敏感路径清单

## 硬性规则
- 不复制真实私钥
- 不复制真实 token / cookie / trusted token
- 不复制真实 `.env`
- 不复制真实录包、真实请求头样本、真实 data 镜像
- 不复制 `重构计划/90_受限资料/` 内容进入本目录

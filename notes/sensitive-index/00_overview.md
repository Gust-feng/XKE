# 敏感边界总览

本目录只保存敏感边界的**元数据索引**，不保存真实内容。

## 目标

- 标记哪些路径属于高敏区域
- 明确哪些内容禁止复制到 `XKE.DotNet8/`
- 为后续脱敏样本、兼容验证、发布排查提供依据
- 把传统 Web 教务系统与移动教务资料分开维护

## 阅读顺序

1. [01_boundary_rules.md](./01_boundary_rules.md)
   - 先确认全局敏感边界
2. [02_sensitive_paths.md](./02_sensitive_paths.md)
   - 再确认父项目、运行数据和受限资料路径
3. [教务系统/00_声明.md](./教务系统/00_声明.md)
   - 开发传统 Web 教务、验证码、Cookie 课表前先读
4. [教务系统/01_接入资料索引.md](./教务系统/01_接入资料索引.md)
   - 传统 Web 教务 v1 “登录 + Cookie 课表”开发入口
5. [移动教务/00_声明.md](./移动教务/00_声明.md)
   - 回归或维护移动教务前先读
6. [移动教务/01_认证流程索引.md](./移动教务/01_认证流程索引.md)
   - 移动教务认证、移动课表和本地缓存回归入口
7. [移动教务/02_运行边界与回归清单.md](./移动教务/02_运行边界与回归清单.md)
   - 已完成链路的运行状态、凭据材料 TTL、失败边界和回归要求

## 索引文件

- [01_boundary_rules.md](./01_boundary_rules.md)：统一规则
- [02_sensitive_paths.md](./02_sensitive_paths.md)：关键敏感路径清单
- [03_external_reference_rules.md](./03_external_reference_rules.md)：外部资料引用规则

## 分类目录

- `教务系统/`：传统 Web 教务系统、验证码、Cookie、课程查询、抢课相关索引
- `移动教务/`：移动教务登录、加密密文材料、运行期 token、移动课表相关索引

## 硬性规则

- 不复制真实私钥
- 不复制真实 token / cookie / trusted token
- 不复制真实 `.env`
- 不复制真实录包、真实请求头样本、真实 data 镜像
- 不复制 `重构计划/90_受限资料/` 内容进入本目录

## 当前开发重心

- 当前主线：移动教务 `/api/auth/*`、`/api/schedule/preferred`、`/api/schedule/local`，用于身份、课表和本地可信状态维护。
- 结构收敛：后端长期结构、测试支持层、Auth/Schedule 行为边界和文档一致性。
- 后置范围：传统 Web 教务验证码、OCR、Cookie 课表、课程查询、选课轮次、课程预览、抢课。

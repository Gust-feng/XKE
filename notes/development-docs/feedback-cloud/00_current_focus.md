# 当前焦点：反馈云函数接入

## 当前切片

把反馈从纯本地 outbox 扩展为“云端优先 + 本地加密兜底”。

## 完成定义

- 私有反馈云函数从 ZIP 整理为可维护目录。
- 云函数本地 `npm run check` 与 `npm test` 通过。
- 客户端新增反馈 HTTP transport，默认读取私有运行时配置。
- 客户端不硬编码真实反馈云函数地址。
- 客户端上传明文学号，云函数保存 `student_id` 并重新计算 `student_id_hash`。
- 客户端本地限制同一学号当天最多 7 条反馈。
- 云端失败时仍能把反馈保存到本地加密 outbox。
- 打包注入脚本写入 `remote.f`。
- WebHost 相关测试覆盖端点解析、transport 注入和上传 payload。

## 设计原则

- 反馈内容和明文学号可能包含敏感信息，云上传必须失败可降级。
- 客户端每日 7 次限制只是应用内体验约束，不能防绕过客户端直接调用云函数。
- 端点不是密钥；真实写权限必须由云函数运行角色、COS 权限和服务端环境变量控制。
- 客户端不保存云端管理 token；如果云函数配置 token，不能把 token 打进公开桌面包。

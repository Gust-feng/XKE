# Schedule Fixtures

This directory contains sanitized Schedule slice samples for DTO, storage, and parser validation.

- `sample_mobile_curriculum.json`: mobile curriculum API sample
- `sample_cookie_schedule.html`: cookie schedule HTML sample
- `sample_schedule_payload.json`: normalized schedule payload sample
- `sample_available_weeks.json`: available week options sample

These samples do not contain real accounts, real cookies, or real tokens.

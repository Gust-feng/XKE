# Course Fixtures

This directory contains desensitized samples for the new .NET Course framework.

- `sample_rounds.json` models normalized course round output used by `GET /api/course/rounds`.
- `sample_preview.json` models normalized course preview output used by `POST /api/course/preview`.

These samples are fake/local only. Do not place real accounts, cookies, captcha data, JW payloads, tokens, or legacy Python cache exports here.

## 课表模型

`GET /api/schedule/semester/local?academic_term=...` 只读后端持久化学期缓存；`GET /api/schedule/semester` 保留为刷新入口。二者使用相同 SemesterDto，支持可选 cached（默认 false，本地为 true），updated_at 保留真实抓取时间。

登录、桌面 bootstrap 与离线恢复均先读本地学期，立即与已有周快照合并；已连接时随后刷新，失败保留已加载数据。已有周上下文时明确传 term；无明确学期时按学期ID选最近已保存学期，再用同学期本地周快照补充日历；没有日历来源时currentWeek/startDate保持未知，不声称已确认学校当前学期。切换学期先读本地，命中后直接使用；仅缺失且已连接时请求网络，失败保留原学期。离线切周缺少周文件时保留学期规则，不自动请求学校。完整学期缓存仍由后端保存，浏览器不新增持久化副本。

同学期同周按有效 syncedAt 的实际时刻比较：新学期排除旧周覆盖，较新单周覆盖该周，等时单周优先；成功空周也遵循相同规则。已知时间优先于未知时间；双方都未知时使用单周的更具体数据，syncedAt 保持 null，不能证明时间先后。空/无效 updated_at 适配为 null，不补机器当前时间。saveWeek/saveSemester 阻止旧数据回退；同账号连接返回的附带周缓存也经 saveWeek 保存，切学期保留内存周快照但只合并同学期。

显示的 scope/syncedAt/cached 来自当前所选周的有效来源，不能显示被新学期淘汰的旧周时间；无所选周数据且无学期时不借其它周的更新时间。空 rows 为有效无课周。失败不修改保存中的快照；目标周没有已获取周快照时明确显示学期安排或暂无课表，不能展示其他周冒充。认证/取消/注销代次与学期选择代次丢弃旧响应；切周不会中断同学期的启动恢复。

显示范围独立于保存数据：学期标签、切换列表和刷新收进左栏学期尺标题，依据服务器enrollment_date至工作区当前学期筛选学校公共目录，缺入学日期只显示当前/已选学期。时间轴优先使用服务器返回的block_times，缺少作息表时才使用已加载课程的真实时间范围；因此不同周的早晚课不会被当前周裁掉，也不会用固定作息覆盖服务器的夏冬时间。完整学期覆盖由semesterLoaded显式标记，不能用所选周scope或学期目录判断；据此裁末尾无课周，保留中间空周、当前周和所选周。所有视图去除title/tooltip重复提示，保留无障碍标签和点击详情。

- week_numbers 转为精确闭区间，保留单/双/跳周，不使用 weeks 原文猜规则。单周显示以返回 viewed week 定位，同时保留 source 原文。
- section_numbers 完整展示；time_segments 先按服务器每个范围适配为原课时，再按下方规则聚合显示，保留完整列表。没有时间/星期/周规则的条目放入未定位课程，绝不计算虚构小节时间。
- 当前周目录的周一日期可反推同学期第 1 周；只有匹配所显示周的源日期或目录值可参与计算。历史无日期时显示 — 并停用倒计时，不用机器今天推算。
- 科目类别未知时使用中性“课程”，不靠名称伪造专业/公共/实践分类。缺教师、教室、学分保持未提供，hours_text/hours_variants 原文独立展示。

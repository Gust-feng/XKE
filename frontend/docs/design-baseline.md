# 正式设计基线

## 2026-10-15 最终demo适配（最新决定）

用户确定XKE-frontend-fixed-20261015.zip为最终视觉/交互基准，要求适配真实runtime，不再沿用此前未获认可的入口试改。连接设置仅从设置页打开560px共享源卡片；三栏设置、左侧个人信息/校园网卡片、课时点阵及汇聚彩蛋按返包保留，不导入备选bak。

设置页个人信息的学期/同步和课时点阵固定消费currentSchedule（最新工作区学期），不随历史浏览schedule切换。点阵按完整学期实际节次、周次及同周新鲜度覆盖后的安排计数，同一原始row的多个时间段只计一次；一次安排最后真实分段结束后才把其节次标为已结束，含义不是考勤。完整旧学期自然全部已结束；单周/部分缓存、缺日期/节次/时间时不展示伪整学期总数，不补早八或固定分钟。小数据不足以汇成可读数字时只展示真实点数，不伪造方点；数据变化/卸载/缩放清理彩蛋，减少动效不播放。

本条覆盖历史左栏入口、420px宽度和“尚未视觉定稿”状态。runtime/preview继续隔离，账号/凭据/API/后台任务边界保持。
